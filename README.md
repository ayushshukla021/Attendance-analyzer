# Attendance Analyzer

A web application that helps college students track,
calculate and maintain their attendance.

## Features

- Current attendance percentage
- Required attendance calculator
- Maximum possible absences
- Lectures required to reach target
- What-if analysis
- Subject-wise tracking
- Local storage
- Responsive UI

## Tech Stack

JavaScript
